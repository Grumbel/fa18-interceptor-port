# F/A-18 Interceptor (R36S / PortMaster)

Modern C++/SDL2 port of the 1988 Amiga flight simulator.

## ADF required

The original disk image is **not** included (not redistributable). Place a
TOSEC copy of `FA-18 Interceptor (1988)(Electronic Arts).adf` in the port
folder (`ports/fa18/`) before launching.

## Controls

Gamepads are mapped through SDL2. Keyboard works when a physical keyboard
is attached.
